# @m0t0k1ch1/ngx

[![npm version](https://img.shields.io/npm/v/@m0t0k1ch1/ngx.svg?logo=npm)](https://npm.im/@m0t0k1ch1/ngx)

A minimal set of UI building blocks for Angular, styled with Tailwind CSS.

## Installation

### 1. Set up Tailwind CSS in your Angular project

Follow the [Tailwind CSS guide for Angular](https://tailwindcss.com/docs/installation/framework-guides/angular).

### 2. Install the package

```
npm install @m0t0k1ch1/ngx
```

### 3. Register the source

Add the following to your global style sheet (`src/styles.css` by default):

```css
@source '../node_modules/@m0t0k1ch1/ngx';
```
